このプロジェクトは、中学生が楽しみながら英語を話す練習ができるAI英会話コーチングツールです。学年別の難易度設定と「3x3マトリックス」のミッション形式を採用し、生徒が自発的にアウトプットできる環境を目指しています。

🚀 特徴
学年別最適化: 中学校1年〜3年までのレベルに応じた対話を提供。

難易度選択: 「Easy（ヒントあり・ゆっくり）」「Normal」「Hard（深掘り質問・自然なスピード）」の3段階。

ミッション形式: "I think..." や "because..." を使う練習をゲーム感覚で進められます。

音声対話: 音声認識と音声合成を活用し、手を使わずに英会話練習が可能。

🛠 使い方
本リポジトリの index.html をブラウザで開きます。

画面の指示に従い、学年を選択してください。

難易度を選択し、英会話を開始します。

「TALK」ボタンを長押し（ホールド）している間、あなたの声がAIに送信されます。

🎯 開発の目的
生徒が英語を話すことへの心理的ハードルを下げる。

自分の意見を論理的に構成する（I think + because）トレーニングを行う。

教室外でも個別最適化された英会話練習の機会を提供する。

⚠️ 注意事項
ブラウザの音声認識機能を使用するため、マイクのアクセス許可を有効にしてください。

通信環境が良い場所でご利用ください。
